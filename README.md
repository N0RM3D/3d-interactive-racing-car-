# 🏎️ 3D Interactive Racing Car - Hand Steering Racer

An interactive 3D racing game built with **HTML5 Canvas**, **TensorFlow.js**, and **MediaPipe Handpose** for real-time hand-controlled steering.

## 🎮 Features

- **Hand-Controlled Steering**: Uses your webcam to track hand position and control the car
- **3D Perspective Racing**: Procedurally generated road with pseudo-3D depth effect
- **Real-Time Performance**: Optimized for mobile devices with frame skipping
- **Neon Aesthetic**: Cyberpunk-themed HUD with glowing UI elements
- **Live Webcam Feed**: Real-time camera preview in the corner
- **Speed Display**: Dynamic speed counter with realistic physics simulation

## 🛠️ How It Works

1. **Camera Permission**: Grant camera access when prompted
2. **AI Model Loading**: TensorFlow.js and Handpose models load in your browser
3. **Start Racing**: Click "START RACING" button
4. **Steer with Your Hand**: Move your hand left/right to steer the car
5. **Watch the HUD**: Monitor speed and steering feedback in real-time

## 📱 Best Experience On

- Desktop with webcam
- Mobile/tablet (place device on stand for best hand tracking)
- Modern browsers (Chrome, Firefox, Safari, Edge)

## 🛣️ Gameplay Mechanics

- **Speed**: Constant at ~185 KM/H with dynamic oscillation
- **Road Curves**: Procedurally generated sine-wave curves
- **Steering Control**: Hand palm position controls left/right movement
- **Visual Feedback**: Color-coded steering labels (LEFT/RIGHT/STABLE)

## 📦 Technologies Used

- **HTML5 Canvas** - Graphics rendering
- **TensorFlow.js** - Machine learning framework
- **MediaPipe Handpose** - Hand pose detection
- **Vanilla JavaScript** - Game logic and physics
